# Data for Coherent Control of Single-Photon Emission in Broadband Plasmonic Resonators

Data used in "Coherent Control of Single-Photon Emission in Broadband Plasmonic
Resonators", by Athul S. Rema, Adrián E. Rubio López, and Felipe Herrera.

Preprint: https://arxiv.org/abs/XXXX.XXXXX

All files are plain text, whitespace-separated, with a header row naming each column.

## Fig1 — controlling emission temporal profiles

Excited-state population `P_e(t) = |C_e0(t)|²` for a quantum dot (`d_eg` = 24 D) at
`h` = 2 nm from a 20 nm-radius silver nanosphere, with `ω_e` = 2.97 eV resonant with
the maximum of `K(ω)`. Both traces use tooth width `σ` = 1 meV and the same per-tooth
amplitude `|D_0|` = 10⁻⁵ a.u.

`Fig1a_Pop.txt` — single tooth at `ω_e` (`N` = 1). Columns: `t_ps` (ps), `Pe_N1`.

`Fig1b_Pop.txt` — comb of `N` = 7 teeth spanning `Γ_K` = 63 meV, with spacing
`Δω` = 10.5 meV and recurrence time `T_rec` = 2πħ/`Δω` = 0.394 ps.
Columns: `t_ps` (ps), `Pe_N7`.
